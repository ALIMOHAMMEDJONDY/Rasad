# رَصَد | Rasad

الخريطة الوطنية للنشاط الإشعاعي في العراق.
Iraq's national radioactivity map.

- **Version:** 1.0 (2026-10-16)
- **Author:** علي محمد جندي (Ali Mohammed Jundi)
- **File:** `index.html` (single self-contained page)

## Features
- Dose calculator: absorbed dose rate, Raeq, Hex, annual gamma dose, radon dose (ICRP/WHO/UNSCEAR reference levels)
- Scientific map of Iraq with governorate boundaries, graticule, scale bar, risk coloring
- Interpolated (IDW) radiation heat layer with confidence fading
- "My dose" shareable card
- Arabic and English interface
- Admin review workflow for submitted readings

## Sources
- Dose coefficients and natural background: UNSCEAR
- Radon reference levels: ICRP, WHO
- Iraq and governorate boundaries: [geoBoundaries](https://www.geoboundaries.org) (CC BY 4.0)
  Runfola D, et al. (2020) geoBoundaries: A global database of political administrative boundaries. PLoS ONE 15(4): e0231866.
